# Local demo assets

Downloaded for offline/local player testing. These are demo clips, not the drama described in the UI.

- `sintel.mp4`: https://media.w3.org/2010/05/sintel/trailer.mp4 — Sintel trailer, Blender Foundation (CC BY 3.0).
- `bunny.mp4`: https://media.w3.org/2010/05/bunny/trailer.mp4 — Big Buck Bunny trailer, Blender Foundation (CC BY 3.0).
- `flower.mp4`: https://interactive-examples.mdn.mozilla.net/media/cc0-videos/flower.mp4 — MDN CC0 video sample.
- `../images/drama-poster.jpg`: https://images.unsplash.com/photo-1483985988355-763728e1935b?auto=format&fit=crop&w=720&q=75 — Unsplash demo poster.

The player uses `/videos/*` and `/images/*`; no remote media requests are needed at runtime.
